## Where finished templates go

The user's destination for every Configurator / Product Price Template is:

    C:\Users\conor.lavery\OneDrive - Kingspan\Commercial\RCA\Claud\Configurator templates

- Running locally on the user's PC (desktop app / terminal): save the final `.xlsx` straight into that folder.
- Running in a cloud session (that path is not reachable): commit the file to the repo under
  `OneDrive_2026-09-29/Claude RCA Product/<NN>-<product>-product-template/`, push, send the file to the
  user, and tell them to save it into the folder above.

File naming: `<Product>_ProductPriceTemplate.xlsx` (e.g. `Airlite_ProductPriceTemplate.xlsx`).
